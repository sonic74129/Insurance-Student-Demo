# 學生保障 Marketplace（合成演示）

**線上入口：** https://sonic74129.github.io/Insurance-Student-Demo/

這是與學校責任險平台分開的純靜態學生端示例。入口提供四個演示角色：學生／家長、保險公司、政府監管、學校。

保障範圍只有兩類：城鄉居民基本醫療保險是依地區政策核實的基礎保障入口，不是平台商品或參保核驗；學平險由多家示例公司提供，是自願商業補充，申請不等於承保或生效。

所有地區、政策、公司、商品、帳戶和申請均為合成資料。沒有官方資格核驗、真實報價、銷售、承保、理賠、支付或後端。請勿輸入真實身份、醫療、學籍、監護或支付資料。

資料只保存在目前瀏覽器的學生端 LocalStorage；不會與學校平台、其他瀏覽器或裝置自動同步。頁面底部可重置本機學生端演示資料。固定演示日期為 2026-10-25。

完整操作步驟請在平台中開啟「操作說明書」。`release.json` 記錄本次公開資產 SHA-256、來源基準提交與工作樹狀態；目前來源工作樹含未提交的學生端變更，請以公開資產雜湊識別實際內容。
