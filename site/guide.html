開始使用

在儲存庫根目錄執行 python .\scripts\serve-student-demo.py，用瀏覽器開啟 http://127.0.0.1:4176/；也可直接打開 demo\student\index.html。選擇學生／家長、保險公司、政府監管或學校。角色僅供演示，不是真實登入。

七步角色操作指南

    商品、核保與理賠演示流程

    1. 保險公司上架：選演示公司，建立草稿，填商品名稱、責任摘要、限額／費用示例、期限、除外、條款版本和來源；保存預覽後提交監管演示審查。
    2. 監管審查：政府監管可對待審商品演示通過、退回修改或拒絕；通過不是實際批准。商品公司只可發布自家獲准商品，並可撤回或建立新版本。
    3. 學生申請：學生／家長只可對已批准且已發布商品提交演示申請。指定的另一家演示公司核保，可要求補充清單、處理重提或記錄通過／拒絕；商品發布公司不能核保自家商品。
    4. 模擬繳費與理賠：核保通過後，學生／家長再次確認模擬繳費才會建立演示保單。只有演示保單可報案；使用抽象責任類別、合成月份／金額和材料清單占位，保險公司可受理、要求補充、形成演示結論、模擬支付並結案。

    居民醫保僅提供地區政策及官方辦理／報銷指引，不模擬官方參保核驗或醫保核賠。申請不等於承保，核保通過不等於已繳費或保障生效；所有保單、理賠結論和支付均無真實法律或交易效力。

    固定合成資料與報表邊界

    程式使用確定性固定資料：三個合成地區、三家合成機構、四所合成學校、年齡分組、SYN-* 識別碼、版本化商品與 12 個固定月份。事故只有抽象類別／月份／虛構金額，材料只有清單占位；不生成姓名、生日、身份、聯絡方式、診斷或文件。政府只看跨區聚合；學校只看本校匯總並抑制低於門檻的分組。畫面數字不可作經營、參保、監管或承保結論。

    展開可複用的固定合成資料提示詞 
    僅從零構造固定、可重現的合成學生保障演示資料，不讀取、改寫、採樣、記憶或仿造任何真實兒童、學校、保險客戶、事故或理賠檔案。使用確定性固定陣列，不使用 Math.random、真實資料推導或網路來源。

建立三個虛構地區 SYN-REGION-A/B/C、三家虛構保險機構 SYN-INSURER-A/B/C、四所虛構學校 SYN-SCHOOL-A/B/C/D，以及 12 個固定月份 2025-11 至 2026-10；演示日期固定為 2026-10-25。政策只作地區居民醫保辦理／報銷核對指引占位，標明政策版本和當地權威來源待確認；不生成官方參保核驗或醫保核賠結果。

兒童流程測試只用 SYN-STU-0001 等 ID 及「演示學生A-001」等明確標籤；年齡只用未滿14歲、14-17歲、18+ 的合成測試分組。代理只用 SYN-GUARDIAN-0001，記錄關聯、有效／撤銷狀態和無意義關係代碼。不要記錄姓名、生日、身份、聯絡或可識別家庭資訊。

建立至少六個版本化學平險商品，只使用 SYN-PROD-*、SYN-SOURCE-* 和合成機構標籤；涵蓋意外傷害、意外醫療及部分商品的疾病住院條款示例。限額、費用、期限、除外、條款版本都標為合成示例，不代表真實報價、批准或銷售。提供草稿、待審、退回、拒絕、批准、發布、撤回狀態。

用 SYN-APP-* 固定案例涵蓋待核保、要求補充、已重提、核保通過待模擬繳費、拒絕及已模擬繳費；用 SYN-POL-* 關聯演示保單；用 SYN-CLAIM-* 涵蓋待受理、審查、補充、重提、通過、部分通過、拒絕、模擬支付及結案。事故只用抽象類別、固定月份和虛構金額；材料只用「材料項1／待演示補充」清單，不寫事故敘事或接收文件。

禁止真實或貌似真實的姓名、身份證號、學籍號、電話、地址、精確生日、真實校名／班級、醫院／醫生名稱、診斷、病歷、發票、照片、定位、真實保單／申請號、支付資訊或可聯絡資訊。所有記錄 ID 以 SYN-* 開始；所有報表標示「合成演示，不可作經營、參保、監管或承保結論」。政府只按地區／學年／月份／公司聚合；學校只看本校聚合並抑制小組；不輸出兒童個體行或個案 CSV。此規範不構成法律合規保證。

    手機操作

    同一平台會依螢幕寬度調整：角色卡直向排列，導航換行，商品以卡片瀏覽；展開商品條款查看來源。手機一次最多勾選兩款比較，其餘商品仍可查看或申請。桌面保留多款完整商品比較。旋轉螢幕不會清除商品選擇或指南步驟。

    指南在手機以底部步驟卡顯示；點全螢幕按鈕閱讀，按 Esc 或退出按鈕返回。帶路只會定位及高亮目標，不會自動切換角色、填表或提交。瀏覽器縮放仍可使用。

    本機資料與保障邊界

    學生醫保是基礎政策入口，需向所在地權威渠道核實資格、辦理、適用期和待遇；學平險是多家公司的自願商業補充，須查正式條款。並非全國統一強制。所有地區、產品、政策和角色操作均為合成示例；沒有真實核驗、報價、承保、理賠或支付。學校端和學生端存檔獨立，瀏覽器間不會自動同步。請勿輸入身份、病歷、學籍、真實監護或支付資料。

    頁尾「重置學生端演示資料」會在確認後清除本機學生端合成紀錄，不影響學校平台。固定演示日期為 2026-10-25。
